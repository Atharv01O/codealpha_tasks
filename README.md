# CodeAlpha Internship Tasks

This repository contains my completed tasks for the CodeAlpha internship.

## Task 1: Exploratory Data Analysis (EDA)

**Notebook:** `Task_1_EDA.ipynb`

Performed exploratory data analysis on a data jobs dataset to understand its structure, identify data quality issues, explore salary distributions, and investigate patterns across job roles and other relevant features.

**Libraries used:**

* Pandas
* NumPy
* Matplotlib
* Seaborn
* SciPy

## Task 2: Data Visualization

**Notebook:** `Task_2_Data_Visualization.ipynb`

Created visualizations to explore the data jobs dataset and communicate insights about salary trends, job categories, experience levels, and other relevant variables.

**Libraries used:**

* Pandas
* NumPy
* Matplotlib
* Seaborn

## Dataset

**File:** `jobs_in_data.csv`

The dataset is used for both tasks.

## Installation

Install the required Python libraries:

```bash
pip install -r requirements.txt
```

Open the notebooks in VS Code or Jupyter Notebook to explore the analysis.
